# Guess-the-number-game
A simple, easy to play, and fun browser game that becomes addicting to play (I hope)

## About
This is a Guess the Number game that I built as part of the Hack Club / Terra challenge
The computer picks random numbers and the user has to attempt to guess it.

## Features
- There are three difficulty levels:
- Easy (Guessing from numbers 1-100, and 10 attempts)
- Medium (Guessing from numbers 1-500, and with 8 attempts)
- Hard (Guessing from numbers 1-1000, with only 6 attempts)
- A counter to track the attempts
- Confetti when you win
- A new game button instead of having to reload the screen
- Pressing enter to guess instead of having to click the button with your mouse which proves to be very useful

## How to play
1. Choose a difficulty before you start playing the game
2. Type in your guess
3. Click the guess button or press Enter
4. Keep guessing until you run out of attempts or win
